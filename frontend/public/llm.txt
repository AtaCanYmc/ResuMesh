## Primary Project: ResuMesh

- **Description**: An AI-powered, open-source smart portfolio aggregator and tailored CV generator.
- **Architecture**:
  - **Public Frontend**: Single page portfolio search client (React + Vite).
  - **Public Backend**: Read-only portfolio service (FastAPI + Supabase).
  - **Admin Frontend**: Dashboard for resource editing, LLM generation triggers, and log parsing.
  - **Admin Backend**: Protected service with JWT auth proxying, LLM CV custom tailoring, and scrapers (FastAPI + Supabase).
- **Core Integrations**:
  - LLM providers (Groq, OpenAI, Ollama) for tailoring CV content from job postings.
  - Supabase Database & Auth.
  - Reactive Resume synchronizations.
  - Background scraper modules for GitHub, Medium, and Dev.to.
- **Source Code**: [github.com/AtaCanYmc/ResuMesh](https://github.com/AtaCanYmc/ResuMesh)
